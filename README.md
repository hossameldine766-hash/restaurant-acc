# Restaurant Management System 🍽️

نظام متكامل لإدارة المطاعم، تم تطويره بلغة Python ليوفر حلاً سريعاً وفعالاً لإدارة العمليات اليومية.

## 🌟 مميزات البرنامج (Features)
* إدارة المبيعات: متابعة ايرادات المبيعات اليومية.
* إدارة المصاريف: إضافة وتعديل المصاريف اليومية.
* إدارة محفظة الكاش: تتبع رصيد محفظة الكاش الخاص بالمطعم
* ادارة الخزينه: متابعة رصيد الخزينة
* ادارة التجار: متابعة رصيد التجار واجمالي المديونيات
* ادارة الفواتير: متابعة الفواتير والتعديل عليها
* ادارة المخزن: تتبع رصيد الاصناف بالمخزن
* ادارة العاملين: تتبع مستحقات العاملين والمكافاءت والخصومات
* التقارير المالية: حساب إجمالي المبيعات والأرباح اليومية.
* واجهة مستخدم بسيطة: تصميم مريح وسهل الاستخدام.

## 🛠️ التقنيات المستخدمة (Technologies)
* اللغة: Python
* واجهة المستخدم: Tkinter
* قاعدة البيانات: SQLite3
* التحويل لملف تنفيذي: PyInstaller
